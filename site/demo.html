Hesewake Notch · prototipe UI dan animasi

Tiruan Canvas 2D dari tampilan dan animasi notch (rilis 0.13.x). Angka pegas, geometri, dan palet diambil dari kode Rust (anim.rs, nav.rs, render.rs, config.rs). Gerakkan kursor ke atas kanvas untuk membuka notch, geser atau klik panah untuk pindah slide, dan ubah parameter di kanan untuk mencoba nilai baru. Teks contoh fiktif.
